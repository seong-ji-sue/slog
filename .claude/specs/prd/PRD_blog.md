**feature**: blog  
**scope**: P2 '블로그 구축' — 홈·전체 글 목록+태그 필터·글 상세·시리즈·소개 5화면  
**작성일**: 2026-07-09  
**근거 SSoT**: `docs/PLAN.md`, `design/mockup-v2.html`

## §0 개요·목적

### 이슈 / AS-IS / TO-BE

| 구분 | 내용 |
|------|------|
| **AS-IS** | 티스토리 블로그(81편 아카이브) 운영 중이나 커스텀·자동화 불가, FE 역량 어필 수단 없음. `seong-ji-sue.github.io` 레포 미존재(신규 구축 필요). |
| **이슈** | 이직 활동 시 포트폴리오로 쓸 수 있는 직접 구축 개발 블로그가 없음. 채용담당자/면접관이 사고 과정을 확인할 수 있는 공개 채널 부재. |
| **TO-BE** | 본인 주력 스택으로 직접 구축한 블로그를 운영함. 블로그 코드 자체가 포트폴리오가 됨. 81편 아카이브를 A·B·C급으로 분류·이관하여 이직용 콘텐츠 자산 확보. |

### 특장점 (기획서 §1 근거)

- 사고 과정과 삽질 기록 중심 콘텐츠 → 면접관이 보는 "기록 포트폴리오"
- `LOG_NNN` 시리얼 번호(티스토리 81편 계승) — 꾸준함 시각화
- 형광펜(`#FFE94A`) 하이라이트·볼펜 블루(`#2451B2`) 카테고리·난이도 별점 — 티스토리 습관을 디자인 시스템으로 승격
- 다크모드 토글 제공(라이트 기본)

## §2 화면·상호작용

### B-01 홈(Home)

**경로**: 사이트 루트 진입  
**신규 화면**

**영역**

| 영역 | 설명 |
|------|------|
| 사이트 헤더 | 로고(`SLOG_`) + 내비게이션 메뉴(글·시리즈·소개·RSS) + 다크모드 토글 |
| 히어로 | Noto Serif KR 900 제목(`무엇이 될지 모르는 <mark>평범한 개발자</mark>의 기록`) + 소개 2줄 bio + 통계 라인(기간·최신 LOG 번호·목표) |
| 피처드(고정 3편) | 글 목록과 동일한 포스트 카드 형태로 운영자가 선정한 3편 고정 노출 — 근거: PLAN.md §5 "피처드 3편" |
| 전체 글 피드 | 최신순 포스트 카드 리스트 (LOG 번호·카테고리·제목·설명·날짜·난이도·읽기 시간) |
| 사이트 푸터 | 저작권 + GitHub 링크 + RSS 링크 + 티스토리 아카이브 링크 |

**목업 관측 근거** (mockup-v2.html ①):
- 헤더: `SLOG_` 로고, `글/시리즈/소개/RSS` 4개 메뉴 링크
- 히어로: h1(Noto Serif) + bio 2줄 + 통계 라인 `2021.12 — ing · LOG 083까지 기록됨 · 주간 1회 목표`
- 포스트 카드: `LOG_083  트러블슈팅` 상단 + 제목(mark 스윕 hover) + 설명 + `날짜 · 난이도 ★★★☆☆ · 분 단위 읽기 시간`
- 푸터: `© 2026 Zibu — 기록으로 증명` + `GitHub · RSS · Tistory 아카이브`

### B-03 글 상세

**경로**: 포스트 카드 클릭 → 개별 글 페이지  
**신규 화면**

**영역**

| 영역 | 설명 |
|------|------|
| 포스트 헤더 | `LOG_NNN · 카테고리 · 날짜 · 난이도 ★` 메타 라인 + Noto Serif h1 제목 |
| TL;DR 블록 | 'TL;DR' 레이블 + 핵심 한 줄 요약(형광펜 mark 적용) |
| 키워드 프리뷰 | `1️⃣ 키워드A  2️⃣ 키워드B` 형태 태그칩 |
| 본문 | ✅ 섹션 헤딩·대화체 인용(볼펜 블루 좌 보더)·코드 블록(다크 아일랜드)·인라인 mark |
| 참고한 링크 섹션 | 마무리 고정 섹션 |
| 시리즈 내비 | 이전 글 ← / → 다음 글 카드 |
| 댓글 영역 | giscus 자리표시(실연동 제외 — §6) |

**목업 관측 근거** (mockup-v2.html ②):
- 포스트 헤더: `LOG_083 · 트러블슈팅 · 2025.07.10 · 난이도 ★★★☆☆`
- h1: Noto Serif 900, mark 적용
- TL;DR: 레이블(`TL;DR`) + mark 인라인
- 키워드칩: `1️⃣ FormData  2️⃣ multipart/form-data`
- 본문 h2: `✅` + check 색상(볼펜 블루)
- 대화 인용: 볼펜 블루 2px 좌 보더
- 코드 블록: `#1D1D22` 배경
- 시리즈 내비: 이전 방향 카드 + 다음 방향 카드
- 댓글: `💬 giscus — GitHub 계정으로 댓글` 자리표시

## §8 impl_requirements

### FE

1. 화면 B-01(홈)은 사이트 헤더(로고+내비+다크모드 토글), 히어로 영역(Noto Serif 제목+bio+통계), 피처드 3편 고정 카드 블록, 최신순 포스트 카드 피드, 푸터를 제공해야 한다.
2. 포스트 카드는 LOG 번호, 카테고리(볼펜 블루), 제목(mark 포함), 설명, 날짜·난이도·읽기 시간 메타를 표시해야 한다.
3. 포스트 카드 hover 시 제목 형광펜이 `background-size: 0% → 100%` 스윕 전환으로 나타나야 한다; `prefers-reduced-motion` 활성 시 transition을 제거해야 한다.
4. 다크모드 토글은 클릭 시 전체 페이지 팔레트를 다크 모드로 전환해야 하며, 라이트 상태를 기본으로 유지해야 한다.
5. 화면 B-02(/posts)는 카테고리 필터 버튼 그룹과 전체 글 카드 리스트를 제공해야 한다; 필터 선택 시 해당 카테고리 글만 노출하고, '전체' 선택 시 복원해야 한다.
6. 화면 B-03(글 상세)은 포스트 헤더(LOG·카테고리·날짜·난이도), Noto Serif h1 제목, TL;DR 블록, 키워드 프리뷰 칩, 본문(✅ 헤딩·대화체 인용·코드 블록·mark), 참고한 링크 섹션, 시리즈 내비 카드를 제공해야 한다.
7. 본문 최대폭은 680px 고정이어야 한다.
8. 코드 블록은 `#1D1D22` 배경의 다크 아일랜드 스타일을 적용해야 하며, 라이트 모드·다크 모드 무관하게 어두운 배경을 유지해야 한다.
9. 화면 B-04(/series)는 시리즈 카드 목록을 제공해야 하고, 시리즈 선택 시 순서 번호가 포함된 해당 시리즈 글 목록을 표시해야 한다.
10. 화면 B-05(/about)는 이력 요약·기술 스택·프로젝트 링크·연락처 4개 영역을 구조로 제공해야 한다; 프로젝트 링크는 외부 URL을 새 탭으로 열어야 한다.
11. 키보드 포커스 시 해당 요소에 형광펜 표시가 나타나야 한다(접근성).
12. 폰트는 Noto Serif KR 900(제목), Pretendard(본문), JetBrains Mono(메타·코드·로고)를 구분해 적용해야 한다.

### BE

1. 글 목록 조회는 `{slug, lognum, title, description, category, date, difficulty, readingTime}` 필드를 포함하는 목록을 반환하는 계약을 제공해야 한다.
2. 글 상세 조회는 `{slug, lognum, title, description, category, date, difficulty, readingTime, tldr, keywords, body, seriesPrev, seriesNext, refs}` 필드를 포함하는 단일 항목을 반환하는 계약을 제공해야 한다.
3. 시리즈 목록 조회는 `{seriesId, title, postCount, lastUpdated}` 목록을 반환하는 계약을 제공해야 한다.
4. 시리즈 상세 조회는 해당 시리즈에 속한 글 목록을 순서 번호(order)를 포함하여 반환하는 계약을 제공해야 한다.
5. 카테고리 필터 조회는 카테고리 값을 파라미터로 받아 해당 카테고리 글 목록만 반환하는 계약을 제공해야 한다.
