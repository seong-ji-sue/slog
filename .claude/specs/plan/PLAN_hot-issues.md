### TASK-BE-5 — 핫이슈 자동 수집 배치 서비스

**kind**: backend | **depends_on**: 없음 (병렬 가능)

**ac_refs 인용**

| AC-ID | Given | When | Then |
|-------|-------|------|------|
| AC-H01-01 | 핫이슈 피드 목록 화면에 진입한 상태 | 화면이 로드됨 | 저장된 이슈가 카드 목록 형태로 수집 시각 최신순으로 표시됨 |
| AC-H01-09 | 저장된 핫이슈가 0건인 상태(최초 수집 전) | 핫이슈 피드 목록 화면이 렌더링됨 | '아직 수집된 이슈가 없습니다' 안내 문구가 표시됨 |

**steps**
1. 고정 출처 목록(Hacker News·GeekNews·Dev.to)에서 신규 이슈를 매일 1회 지정 시각에 수집하는 배치 작업 구성 (스케줄 프리셋값 주입)
2. 수집된 원문 URL 기준으로 기존 저장 항목과 중복 여부를 판정 — 이미 저장된 URL이면 저장을 건너뛰고 기존 항목 유지
3. 신규 이슈의 원문 내용을 한국어로 요약해 수집 시점에 1회만 생성·저장 — 요약 실패 시 요약 필드를 비운 채 나머지 필드(제목·출처·수집일·원문 URL)는 정상 저장
4. 특정 출처 수집 실패 시 해당 출처만 건너뛰고 나머지 출처 수집은 계속 진행하는 격리 로직 구현; 원문 접근 실패 이슈는 저장·노출 대상에서 제외
5. 특정 수집 주기에 신규 이슈가 없으면 기존 저장 목록을 그대로 유지
6. 수집된 이슈는 삭제 로직 없이 무기한 누적 보관

**success_criteria**: AC-H01-01 GREEN, AC-H01-09 GREEN
