# 말투·문체 스타일 가이드 (Zibu Voice)

티스토리 81편(2021~2025) 정량 분석 기반. 신규 글과 이관 글 리라이트에 적용함.

## 정량 분석 요약

| 항목 | 수치 | 해석 |
|------|------|------|
| 어미 "~다/된다/이다" | 1,464회 | 평어체 서술이 기본 |
| 개조식 "~음/함/됨/임" | 420회 | 리스트·요약에서 사용 |
| 존댓말 "~요/습니다" | 143회 | 2021 초기 글 위주 (혼용 → 통일 필요) |
| ✔️ 헤딩 마커 | 305회 | 시그니처 #1 |
| "난위도 : ★" 별점 | 44편 | 시그니처 #2 (오타 포함) |
| `~!` / `~!!` | 376회 | 활력체 — 절제 필요 |
| ㅋㅋ/ㅎㅎ | 52회 | 이직용 공개 글에서는 제거 |
| 1인칭 | 나는/내가(67) 필자(32) 저는/제가(41) | "나" 계열로 통일 |

시대 변화: 2021(50편) 학습노트·이모지 헤비 → 2023(16편) 실무 전환 → 2024~25(4편) 트러블슈팅 서사 + 대화체 도입부로 정착. **신규 글 기준은 2025년 스타일(219번 글)임.**

## 핵심 시그니처 (유지할 것)

1. **난이도 별점** — 글 상단 `난이도 : ★★★☆☆` (※ 원문 오타 "난위도" → "난이도"로 교정)
2. **✅ 섹션 마커** — h2/h3 앞에 `✅ ` (구버전 ✔️ 는 ✅ 로 통일)
3. **1️⃣2️⃣ 키워드 프리뷰** — 도입부에 핵심 개념 2~3개를 숫자 이모지로 예고
4. **대화형 도입** — 실무 글은 요구사항을 대화로 재연:
   > 설계 부장님 : 인증서를 UI에서 첨부해야 돼~
   > 예스맨 : YES! 단건은 데이터와 같이, 라이센스는 3개 파일 전송~
   - "예스맨" = 본인 페르소나. 유지하면 글에 개성 생김
5. **핵심 한 줄 요약** — 글 최상단 인용구(원문의 노란 하이라이트 계승 → 블로그에선 `> **TL;DR**`)
6. **참고한 링크** — 마무리 고정 섹션 (원문 "참고한 링크/사이트" 계승)

## 어미 규칙

- 본문 서술: 평어체 `~다 / ~된다 / ~이다` — "FormData에 파일과 데이터를 넣어서 보내야 된다."
- 리스트·표·요약: 개조식 `~음 / ~함 / ~됨 / ~임`
- 존댓말(`~합니다`) 금지 — 인용문 제외. 글 안에서 혼용하지 않음
- `~!` 는 문단 마무리 포인트에만 글당 2~3회 (원문은 남발 — 절제)
- 셀프 츳코미("크~명언~!" 류) 글당 1회 이하 — 개성은 살리되 이직용 절제

## 1인칭·사고 서술

- "나는/내가" 기본. "필자" 사용 안 함 (2021 유산)
- 사고 과정을 숨기지 않음: "가장 먼저 드는 생각이 '어떻게 그릴까?'였다" — 이 스타일이 강점, 유지
- 삽질도 기록: 면접관이 보는 것은 결과보다 사고 과정임
