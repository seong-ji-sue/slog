## ✅ 배운 것 / 한 것

- 백엔드·프론트엔드를 종합적으로 초기세팅할 때 무엇을 해야 하는지 복습
- `export default`는 값을 하나만 내보내야 하고, 여러 개를 내보내려면 객체로 묶어야 한다는 것
- 하나의 프로세스 안에 여러 스레드가 있지만, 자바스크립트가 직접 제어할 수 있는 스레드는 하나뿐이라 싱글 스레드 방식을 쓴다는 것
- 콜백이 호출 스택에 쌓이고, 논 블로킹 함수는 백그라운드로 타이머와 함께 이동한 뒤 태스크 큐를 거쳐 호출 스택이 빌 때 다시 올라와 실행된다는 것
- `axios`와 `fetch`의 차이는 단순한 편이고, `async/await`는 `fetch`의 축약형이라는 것
- `FormData` 객체로 POST 요청 시 담을 데이터를 따로 분류할 수 있다는 것

## ✅ 추각코 복습 가이드라인

노션에 올라온 가이드를 참고해서 아래 순서로 복습했다.

**1. 자바스크립트 비동기**

JavaScript의 동작 원리를 한 번 정리하면 비동기도 함께 이해할 수 있다. 아래 단어들을 질문받았을 때 당황하지 않고 답할 수 있도록 정리했다.

- Chrome V8(완료)
- Runtime Environment(완료)
- Single Threaded(완료)
- Call Stack(완료)
- Event Loop(완료)
- Concurrent
- Non Blocking(완료)

**2. React**

3주 동안 리액트를 손에서 놓으면 감이 떨어질 수 있다. 몬스터 카드 리스트·필터링 자료를 복습하고(살짝 완료), Webucks에서 구현했던 것들을 다시 짜보면서 State, Props, Event, Life Cycle, Fetch, Mock data를 복습했다.

**3. Node.js, Express (아직 미흡)**

노드와 Express의 기본기를 책과 공식 문서로 학습하고, 이후 Layered Pattern 같은 디자인 패턴과 best practice, boilerplate를 찾아 학습하는 게 다음 단계다.

**4. Database & Prisma (완료)**

원하는 사이트를 모델링하면서 헷갈리던 one-to-one, one-to-many, many-to-many 관계를 정리했다. Prisma를 연결해서 migration까지 진행했고, Raw Query를 반복적으로 써보면서 익숙해지려 했다.

## ✅ 배운 점 / 아쉬운 점

**잘한 점**

- 미션과 블로그 정리부터 우선순위를 두고 시작한 것 — 미션은 기본적인 자바스크립트·노드 개념이 없으면 못 풀리기 때문에 MVC 나누기와 쿼리문 작성에 집중했다
- 모르는 부분(쿼리문, 모듈 등)이 나오면 구글링이나 코드잇 강의로 바로바로 개념을 잡아간 것
- 매일 홍대 위워크로 출근하면서 학습 방법이나 모르는 것을 동기들에게 물어보며 해결한 것

**아쉬운 점**

- 노션에 정리된 추각코 범위가 워낙 방대해서 처음엔 어디서부터 시작해야 할지 감이 안 잡혔던 것 ㅋㅋ
- 하루 이틀 정도는 그냥 쉬어버린 것 — 다른 사람들보다 미션을 많이 진행한 건 아니었다
- 1주가 더 추가된 일정을 복습 기회로 삼기는 했지만, 길게 늘어지는 것보다 빨리 끝내는 편이 나았을 수도 있겠다는 생각
