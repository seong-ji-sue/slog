## ✅ 왜 이 파트를 놓치면 안 되나

네트워크관리사 필기를 열심히 암기했다면 실기 이론 파트에도 공통되는 항목이 많이 나온다. 설정이나 라우터 명령어를 마스터해도 이 파트를 대충 넘기면 떨어질 수 있다. 여기 정리한 문제는 필히 암기하고 가는 게 좋다. 객관식·주관식 문제까지 잡아야 60점 이상 합격선에 들어선다.

## ✅ 문제 총 정리

> 출제 유형: 리눅스 명령어, 용어 관련 문제, 네트워크 IP 문제

### 리눅스 명령어

1. 리눅스에서 ip address 정보를 확인하는 명령어는? — `ifconfig`
2. 리눅스에서 파일이나 폴더를 찾을 때 쓰는 명령어는? — `find`
3. 리눅스에서 현재 설치된 하드디스크와 용량을 확인하는 명령어는? — `df`
4. 리눅스에서 현재 위치를 확인하고 싶을 때 쓰는 명령어는? — `pwd`
5. 리눅스에서 도움말 매뉴얼을 확인하는 명령어는? — `man`
6. 리눅스에서 파일 또는 디렉토리를 삭제하는 명령어는? — `rm`
7. 리눅스에서 네트워크 연결 상태, 라우팅 테이블 정보 등을 보여주는 명령어는? — `netstat`
8. 리눅스에서 물리적 장치를 특정 위치로 연결시켜주는 과정은? — `mount`
9. 리눅스에서 물리적 장치를 특정 위치로 연결한 것을 해제하는 명령어는? — `unmount`
10. 프로세스의 수행을 종료시키는 명령어는? — `kill`
11. 리눅스에서 포트 번호를 출력하는 명령어(파일)는? — `/etc/services`
12. 정적 라우팅 설정 명령어는? — `ip route ~~~`
13. 리눅스 시스템에서 CPU 및 메모리 사용 정보를 확인하는 명령어는? — `top`
14. ping을 정상적으로 사용할 수 있도록 (A) 빈칸에 들어갈 내용을 입력하시오. `# echo (A) /proc/sys/net/ipv4/icmp_echo_ignore_all` — 답 `0`
15. 리눅스에서 지정된 호스트에 도달할 때까지 통과하는 경로 정보와 경로에서의 지연 시간을 추적하는 명령어는? — `traceroute`

### 용어 관련 문제

1. IPv4와 IPv6를 함께 사용할 수 있는 장비는? — 듀얼스택
2. OSI 7계층 중 3계층(네트워크 계층)에 속하며, LAN과 LAN 또는 LAN과 WAN 등을 연결하고 최적 경로를 설정하는 장치는? (Switch 2개를 연결) — 라우터
3. 스위칭 허브에서 포트를 물리적으로 바꾸지 않고 소프트웨어로 LAN망을 구분하는 것은? — VLAN
4. Cisco Router의 Interface 중, 내부 네트워크(랜)를 위한 접속 포트로 UTP 케이블 연결을 위해 MAU 트랜스를 쓰는 A 포트, 외부 네트워크 접속을 위한 포트로 DSU/CSU 연결에 v.35 케이블을 쓰는 B 포트는 각각 무엇인가? — A: ethernet, B: serial
5. 서버 한 대 이상이 고장 나도 서비스가 계속되도록 여러 서버를 하나의 거대한 시스템처럼 연결하는 기술은? — 클러스터링
6. 외부에 공개된 웹 서비스의 HTTP/HTTPS 보안 취약점(IPS로는 패킷 필터링 한계로 SSL 검사 불가, 웹 취약점을 이용한 변조·계정 도용 등)을 방어하는 네트워크 기술은? — 웹방화벽
7. 하나의 자율 시스템(AS)에서 링크 스테이트 라우팅 알고리즘으로 동작하는 최단 경로 우선 프로토콜은? — OSPF
8. 인터넷망 같은 공중망을 사설망처럼 이용해 회선 비용을 절감하는 기업 통신 서비스는? — VPN
9. 공격 서명을 찾아내어 자동으로 조치를 취해 비정상 트래픽을 중단시키는, IDS와 달리 능동적으로 공격을 차단하는 보안 솔루션은? — IPS
10. 네트워크 스위치의 한 포트에서 보이는 모든 패킷(또는 전체 VLAN)을 다른 모니터링 포트로 복제하는 기술은? — 포트 미러링
11. 모든 호스트에 공인 IP를 낭비 없이 쓰기 위해 내부적으로 사설 IP를 쓰고 인터넷 접속 시에만 공인 IP로 변환하는 기술은? — NAT
12. 2개 이상의 다른 혹은 같은 통신망을 상호 접속해 통신망 간 정보를 주고받게 하는 장치는? — 게이트웨이
13. 데이터링크 계층(MAC 계층)에서 두 세그먼트 사이의 패킷 전송을 담당하는 장치는? — 브릿지
14. 매니지먼트와 에이전트 사이에서 관리 정보를 주고받는 프로토콜은? — SNMP
15. TCP/IP 기반 네트워크에서 서버나 라우터가 에러나 예상치 못한 사건을 보고할 목적으로 만들어진, RFC 792에 정의된 프로토콜은? — ICMP
16. 동적 디스크 볼륨 중 하나의 디스크가 손상돼도 다른 디스크의 데이터로 복구할 수 있는 내결함성 볼륨(RAID1, RAID 0+1)의 이름은? — 미러링
17. 임의로 구성된 웹사이트를 통해 이용자의 정보를 빼가는 해킹 수법은? — 스푸핑
18. 이미 발견된 공격 패턴을 미리 입력해두고 해당 패턴을 탐지하는 기법(signature base, knowledge base)은? — 오용 탐지 기법
19. 근거리에서 저전력으로 무선 통신하는 표준(IEEE 802.15, 인텔·IBM·노키아·에릭슨 공동 개발, 최대 범위 10M, 1Mbps)은? — 블루투스
20. Server Load Balancing에서 가장 많이 쓰는 방식은? — Round Robin
21. A 허브는 포트에 연결된 컴퓨터의 MAC 주소를 몰라서 신호를 보낼 때 모두에게 전송하고, B 허브는 내부 메모리 테이블에 MAC 주소를 기록해서 해당 포트로만 전송한다. A와 B는 각각 무엇인가? — A: 더미허브, B: 스위칭 허브
22. 스위치를 중복 사용하면 신뢰성은 올라가지만 A 문제(루핑)가 생길 수 있어, IEEE 명세서에서는 A가 발생하지 않는 토폴로지를 만드는 B 알고리즘을 요구한다. A와 B는? — A: 루핑, B: STP
23. VPN 터널형 프로토콜 중 2계층(링크 계층)에서 사용하는 프로토콜을 모두 선택하시오 — L2F, L2TP, PPTP
24. 시스템의 상태 정보나 데이터를 그래프로 그려주는 그래픽 툴로, 설치가 쉽고 SNMP로 읽을 수 있는 데이터 외에도 다양한 정보를 그래픽으로 출력할 수 있는 freeware 모니터링 도구는? — MRTG
25. 허용 가능한 범위의 IP 주소를 이용해 허가받은 사용자인 것처럼 위장하는 (A) 공격과, 네트워크 상의 다른 컴퓨터에 로그인·명령 실행·파일 복사를 안전하게 해주는 (B) 암호화 접속 방식은? — (A) IP-스푸핑, (B) SSH
26. 포트에 연결된 컴퓨터의 MAC 주소를 몰라 신호를 모두에게 전송하는 (A) 허브와, 내부 메모리 테이블에 MAC 주소를 기록해 해당 포트로만 전송하는 (B) 허브는? — (A) 더미, (B) 스위치

### 네트워크 IP 문제

1. 괄호 안에 들어갈 IP 주소 클래스 비트 수는? `10.x.x.x/A`, `172.16.x.x/B`, `192.168.9.x/C` — A: 8, B: 16, C: 24
2. IP `172.150.72.1`와 서브넷 마스크 `255.255.224.0`을 바탕으로 네트워크 ID를 구하시오 — `172.150.64.0`
3. 할당 가능 네트워크 주소가 2^14개, 할당 가능 호스트 주소가 2^16개인 클래스는? — B 클래스
4. IPv4와 IPv6에 대한 설명 중 빈칸을 채우시오. IPv4: (A)bit × (B)개 = 32bit, (C)진수, 유니캐스트, 멀티캐스트, (D). IPv6: (A)bit × (B)개 = 128bit, (C)진수, 유니캐스트, 멀티캐스트, (D) — IPv4: 8, 4, 10, 브로드캐스트 / IPv6: 16, 8, 16, 애니캐스트
