## **T M I**

**Spring Intializr 로 프로젝드를 생성하면**

**자동으로 빌드나 부트등 자동으로 생성하기 때문에 유용하다.**

**Dependencies를 통해 필요한 라이브러리를 설치할 수도 있다.**

**필자는 IntelliJ를 유료로 사용중이며 Java 11 버전을 사용하고 있다.**

**코드 내용**

**[깃허브 Repository](https://github.com/seong-ji-sue/springboot-inflearn-kimyounghan-basic)**

![](../images/197/img_02.gif)

📢 **스프링 프로젝트를 생성하고 실행해서 웹 브라이우저에 Error 페이지를 띄울수 있습니다.**  
**📢 준비물 Eclipse or IntelliJ Spring Intializr 에서 생성한 프로젝트 폴더 자바 11 버전**

### **✔️**프로젝트 생성 방법**

> **필자는 IntelliJ 사용, Preferences → Gradle 들어가서 Build, Run IntelliJ 로 바꾸기**

1. Eclipse or IntelliJ 설치
2. 아래 링크에서 스프링 프로젝트 생성하고 다운 받기
   - Project : Gradle Project
   - Spring Boot : 최신으로
   - Language : Java
   - Packaging : Jar
   - Java : 11
   - Dependencies : Spring Web, Thymeleaf(View 탬플릿 엔진)
3. Eclipse or IntelliJ 로 프로젝트 열기
4. 실행 후 8080 포트에 들어가 Error 페이지 확인

**스프링 프로젝트 생성하는 곳 : [Spring Initializr](https://start.spring.io/)**

### **✔️**빌드하는 방법**

> **window 기준으로 작성한 내용 입니다.**

```armasm
cd 프로젝트 폴더
./gradlew.bat build
cd build/libs
java -jar hello-spring-0.0.1-SNAPSHOT.jar
```
